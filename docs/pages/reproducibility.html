Reproducibility

Every analysis step is documented, versioned, and reproducible from publicly available data.

How to Reproduce This Analysis
Terminal — Step by step 
# Step 1: Clone the repository
git clone https://github.com/[YOUR-USERNAME]/pdac-circuit-framework.git
cd pdac-circuit-framework

# Step 2: Open R 4.6.0 and install all packages
Rscript R/00_setup.R

# Step 3: Download public datasets
# Follow instructions in data/README_data.md
# TCGA-PAAD → UCSC Xena · GSE183795 → GEO · DepMap → depmap.org

# Step 4: Run analyses in order
Rscript R/01_data_acquisition.R   # Download + preprocess data
Rscript R/02_circuit_scores.R     # Compute CDS + assign subtypes
Rscript R/03_subtype_clustering.R # ConsensusClusterPlus 1000x
Rscript R/04_survival_analysis.R  # Cox · KM · C-index · DCA
Rscript R/05_external_validation.R# Apply to GSE183795 without retraining
Rscript R/06_gsea.R               # fgsea Hallmark enrichment
Rscript R/07_boolean_network.R    # BoolNet attractor analysis
Rscript R/08_crispr_dependency.R  # DepMap essentiality screening
Rscript R/09_classifier.R         # Elastic net + permutation + SHAP
Rscript R/10_correlation_matrix.R # Spearman cross-circuit correlations
Rscript R/11_figures.R            # Generate all manuscript figures
